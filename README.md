# SQL Data Jobs Analysis 📊

## 📌 Project Overview

This project uses PostgreSQL to explore the data job market, focusing on job salaries, in-demand skills, and the relationship between skills and earning potential.

The goal is to use SQL to extract meaningful insights from job posting data and better understand the skills employers seek in data-related roles.

## 🎯 Business Questions

This project investigates five key questions:

1. What are the highest-paying data-related jobs?
2. Which skills are associated with the highest-paying jobs?
3. Which skills are most in demand?
4. Which skills are associated with higher salaries?
5. Which skills offer a strong combination of demand and salary potential?

## 🛠️ Tools & Technologies

- **PostgreSQL** — Database querying and analysis
- **SQL** — Data exploration and analysis
- **Visual Studio Code** — SQL development environment
- **SQLTools** — PostgreSQL connection and query execution
- **Git & GitHub** — Version control and project hosting
